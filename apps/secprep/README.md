# SecPrep Daily

A Security+ (SY0-701) study app in **English, French and Haitian Creole** for iPhone and Android.

The app includes:
- 189 practice questions with explanations
- a timed 90-question mock exam
- spoken lessons for all 5 exam domains
- 6 narrated incident scenarios
- a daily streak and an optional daily reminder

The app is built with [Capacitor](https://capacitorjs.com). It is a plain HTML/JS app in `www/`, wrapped in native iOS and Android projects. It works fully offline.

> The questions are original. They are written to the official SY0-701 exam objectives, and they are **not** real exam questions. CompTIA's exam content is confidential. The app is not affiliated with CompTIA.


## Editing questions

Each question is one line in `www/data/<lang>.js`:

```js
[domain, "question", "correct answer", ["wrong 1", "wrong 2", "wrong 3"], "explanation"]
```

The correct answer is always written first, and the app shuffles the choices. Keep questions in the **same order** in all three files, then run `npm run check`.

## The voice

The app uses the phone's own text-to-speech. It uses the native plugin `@capacitor-community/text-to-speech` in the app and the Web Speech API in browsers. To make it sound more human, it:

- picks the best installed voice (Premium, Enhanced or Neural voices first)
- speaks one sentence at a time, with real pauses
- varies pitch and pace slightly on every sentence
- uses a warmer, upbeat tone for praise and a softer, slower tone for corrections
- adds coach-style transitions such as "Okay, here's the next one…"

Users get a much better voice by downloading one:
- **iPhone:** Settings › Accessibility › Spoken Content › Voices, then pick a Premium or Enhanced voice.
- **Android:** Settings › Text-to-speech, then install Google's high-quality voices.

Phones have no Haitian Creole voice, so Kreyòl is read with a French voice.

To get a studio-quality human voice in all three languages, record or generate audio files ahead of time and ship them with the app. See "Upgrading the voice" in `STORE_GUIDE.md`.
