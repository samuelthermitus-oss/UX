# Design previews

- `ionic-liquid-glass-preview.html`: interactive preview of the app built with Ionic Framework 9 components and a Liquid Glass style. Open it in a browser. It includes background themes (Original, Ocean, Glacier) and Light / Dark / Auto appearance. It loads Ionic from the jsDelivr CDN, so it needs an internet connection.
- `dark-mode-preview.png`: dark mode for the three themes, plus the Practice and Settings screens.

These are previews only. The shipping app in `www/` does not use Ionic yet.
